# kidChinese · 小学生认字

一年级识字 H5 练习页：主页认字、考试录音、历史回放。

字库来自《识字文字版》PDF 第 1–12 页（已去除「一上」「一下」年级标记），共 662 个字。

## 功能

- **主页**：随机顺序展示汉字，含组词与造句，右下角可切换上一个 / 下一个
- **考试**：随机抽 20 个字，支持录音；不评分，不强制录音
- **历史记录**：查看历次考试，逐字回放录音

录音与历史保存在浏览器 IndexedDB 本地，不会上传服务器。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash

npm run preview
```
